This game currently has different items the player can pick up.  I want a "crafting" system, where players can drop/throw things into a cauldron to create net new items.  most (if not all) of the created items will be consumables for local and remote players (for starters, we can just build the crafting system around consumables, but ensure it is extensible to be able to create anything).  consumables are items that can be held, thrown, and used.  If a consumable is thrown, when the item hits something (ground, environment, another player, etc.), it produces a 'cloud' with an AoE of the effect.  This effect can either be instantaneous, and everyone in the AoE gets this effect for the specified time, OR it can be a lingering effect in the status area.  For example, the instantaneous effect could be a speed boost, causing the player to move faster for the specified amount of time.  the lingering effect could be a health zone, where the player slowly gains health while inside of the zone.  If an item is used (let's use right click on mouse or left trigger on controller for this), then the item acts as if it was thrown directly at the using player (i.e. the zone appears directly on the player, but we don't need to animate a throw or anything, just use immediately).

For the cauldron/crafting, I want this networked; any player should be able to see the same cauldron with the same contents.  we'll have 2 cauldron states: inactive (nothing inside), and active (we'll have some particle effects while active, this happens when at least 1 item is inside).  max items in a cauldron is 3.  players can either throw an item inside (so when an item hits the trigger collider, it lerps through a spline directly above the cauldron, then lerps down into the cauldron, triggering a particle effect), or players can equip an item in the hand, walk to the cauldron, and interact with it to place the item (tooltip on cauldron that says "insert item").  if a players hands are empty, 2 tooltips appear on cauldron hover -- "brew" or "dispose".  brew attempts to create an item.  if nothing can be created,  there should be a 'poof' and a cloud of smoke (particle effects) and the players within range (configurable) should take some damage (also configurable).  if something can be created, we show a brief particle effect, and the new item rises from the cauldron and hovers over the cauldron until a player interacts with the item to pick it up.  nothing else can be brewed until the crafted item is picked up.

the cauldron should have a world space UI with 3 square panels.  each item placed inside should display the icon of the item on one of the panels.  items placed in the cauldron are destroyed forever.

for the first item, let's do health potions.  1 mushroom should make a small health potion, 2 medium health potion, and 3 a large health potion.  Any holdable item should be placeable in the cauldron.  ensure we do this with the most minimal network messages as possible (i.e. we just send an rpc that says "user x placed y in the cauldron", and the other remote clients replicate the movement.  then when a user clicks craft, we rpc that message to all players to kick off the particles and item rising animation).

as a second item, combining a basketball with anything (needs to be at least 1 other item) creates a jump/bouncy potion.  this lets the player jump high, but also causes them to bounce when they land (explore the best way to accomplish this, maybe its a physics material, but it should be easily networked with minimal network messages).

this work may require some adjustments to the player controls, since some crafted items can imbue new movement abilities on the avatar.  ensure our character movement system can accommodate for these new abilities and that they seamlessly slot on top of existing avatar behavior.
